# Ubuntu Home Lab

## Practical Linux Administration Portfolio

This repository documents my hands-on Ubuntu Linux home lab.

The purpose of this project is to develop and demonstrate practical skills in:

- Linux administration
- Linux permissions
- SSH
- Networking
- NGINX
- System monitoring
- Troubleshooting
- Bash
- Infrastructure administration

## Lab Environment

- Operating System: Ubuntu Linux
- Environment: Virtual Machine
- Shell: Bash
- SSH: OpenSSH
- Web Server: NGINX
- Monitoring: htop

## Projects

### 01 - Linux Fundamentals
Linux filesystem, directories and essential commands.

### 02 - Linux Permissions
Users, groups, ownership and file permissions.

### 03 - SSH
Remote administration and SSH key authentication.

### 04 - NGINX
Web server and reverse proxy configuration.

### 05 - System Monitoring
CPU, memory, processes and system resource monitoring.

### 06 - Networking
Linux networking, IP addressing, ports and connectivity testing.

### 07 - Troubleshooting
Documenting real problems, investigation and solutions.

## Learning Approach

I am building this lab to move from theoretical knowledge toward practical Linux and infrastructure administration.

Each project documents:

- Objective
- Commands
- Configuration
- Testing
- Verification
- Screenshots
- Troubleshooting
- Lessons learned
